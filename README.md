# 四项机器学习课程设计：提交对应源码

本仓库整理了四项课程设计任务的完整代码入口，分别对应植物幼苗分类、人脸表情识别、黄斑中心凹定位和眼底血管分割。代码按照最终提交方案组织，包含训练、验证、预测、后处理和提交格式转换功能；数据集、预训练权重和生成文件由使用者在本地准备。

## 任务与方法

| 任务 | 主要方法 | 提交输出 |
|---|---|---|
| 任务一：植物幼苗分类 | ConvNeXt-Tiny、五折交叉验证、EMA、四视图测试时增强 | `ID,Category` |
| 任务二：人脸表情识别 | ConvNeXt-Tiny、ResNet34、EfficientNet-B0，固定对数概率融合 | 六分类标签 |
| 任务三：黄斑中心凹定位 | ConvNeXt-Small 概率热图、不同尺度训练、四组预测融合 | `ImageID,value` |
| 任务四：眼底血管分割 | 四通道输入、U-Net 与预训练编码器、三类模型家族融合、RLE | `Id,Predicted` |

## 目录结构

```text
mltask1/                  任务一训练与预测入口
mltask2/src/              任务二数据审计、训练和固定融合
mltask3/src/              任务三热图模型与坐标提交生成
mltask4/                  任务四训练、集成推理和RLE转换
requirements.txt          Python依赖说明
PACKAGING_NOTES.md        代码组织与运行说明
```

## 使用说明

建议使用 Python 3.10 或更新版本，并根据 CUDA、PyTorch 与 torchvision 版本选择相互兼容的环境。先安装 `requirements.txt` 中的基础依赖，再按照各任务 README 准备数据和预训练权重。训练任务需要 GPU；提交格式转换和已有预测结果的整理可使用 CPU。

各任务 README 给出模型配置、输入输出格式、运行命令及实验指标。运行时请将数据、权重和输出目录设置为本地路径，不要将数据集、权重或提交文件加入代码仓库。
