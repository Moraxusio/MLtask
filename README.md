## 训练标签、外部答案与代码范围

作者确认实验未使用外部答案。收录代码没有外部答案、测试真值或上传提交文件读取逻辑；模板只提供ID/格式。生成后与上传CSV的匹配核验在仓库外完成，不通过读取上传CSV生成预测。

**任务二的训练重复图后处理必须保留。** 它对解码后的48×48像素求哈希，若测试图存在训练副本且其训练标签一致，则使用该训练标签；冲突保持模型预测。实际520行有匹配、36行改写、9行冲突跳过。这些数字是运行后统计，不是代码中的样本答案或修改清单。该步骤依赖训练/测试重叠，不是纯网络泛化，36行改写也不等于36次纠错；本仓库不对未知任务规则的许可性作保证。

任务一保留同一模型的EMA/Mixup消融能力；任务三限于实际stage1 Small、两种尺度、CV/full流程，已删除二阶段、其他骨干及外部训练数据分支；任务四共享模型构建代码由所需训练入口使用，实际预测精确枚举35个权重，不扫描额外模型、不重新调阈值。详见 [PACKAGING_NOTES.md](PACKAGING_NOTES.md)。

## 使用与复现边界

建议Python 3.10或更新的兼容环境。`requirements.txt` 是必要依赖清单，**不是历史环境锁**：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

安装与CUDA匹配的torch/torchvision，按各任务README自行准备合法课程数据和预训练权重。多数训练流程要求CUDA/BF16。不要把数据、权重或凭据加入Git。

当前核验范围：

- 任务一：实际CSV字节匹配，训练配置与代码/日志对应。缺最终权重和逐样本概率，未从预测重建。
- 任务二：已有折预测→固定融合→训练重复图修正→CSV，全部7065行字节重建一致。
- 任务三：四份已有预测→等权坐标平均→CSV，全部40行字节重建一致。
- 任务四：已有20张掩码→RLE→CSV，字节重建一致；另外检查了35份权重结构兼容性及已有OOF，但未重跑网络推理。新固定入口按ID升序写CSV，可能仅行序与历史目录顺序不同。
- 未重新训练、未模型推理，不承诺新环境端到端重训结果逐字节一致。任务三早期CV权重无当前代码的辅助reg头，版本缺口详见其README。
- 历史分折中的近重复/重复跨折与OOF选择偏差如实保留说明，不能由提交文件匹配推导独立泛化能力。
